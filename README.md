# WARDOGS Range Calculator

Одностраничный калькулятор дальности для миномёта L81 и артиллерийского танка SPH-2 в WARDOGS.

## Локальный запуск

Откройте `index.html` двойным щелчком

## Как дать ссылку в руководстве Steam

Разместите ссылку сразу после короткого вступления:

> **Открыть калькулятор дальности для WARDOGS**  
> Вставьте координаты орудия и цели — калькулятор покажет значение для шкалы RNG.

Ниже лучше оставить три скриншота: получение координат орудия, получение координат цели и готовое значение RNG. Формулу и частые ошибки разместите в конце руководства как необязательную справку.
