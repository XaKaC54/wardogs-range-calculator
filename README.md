# WARDOGS Range Calculator

Одностраничный калькулятор дальности для миномёта L81 и артиллерийского танка SPH-2 в WARDOGS.

## Открыть калькулятор

**[Открыть калькулятор дальности](https://xakac54.github.io/wardogs-range-calculator/)**

Инструмент работает прямо в браузере: вставьте координаты орудия и цели, затем перенесите рассчитанное значение на шкалу RNG в игре.

## Локальный запуск

Откройте `index.html` двойным щелчком.

## Как дать ссылку в руководстве Steam

Если Steam пропускает GitHub, используйте ссылку на репозиторий: [github.com/XaKaC54/wardogs-range-calculator](https://github.com/XaKaC54/wardogs-range-calculator). На его первой странице есть заметная ссылка на калькулятор.
